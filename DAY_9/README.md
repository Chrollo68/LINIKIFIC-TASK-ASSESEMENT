# DAY 9 Flutter Animations

This project demonstrates Flutter animation concepts through hands-on examples.

## Learning Objectives
- Understand Flutter animations
- Create implicit animations
- Build explicit animations
- Implement custom transitions
- Explore Hero animations and shared element transitions

## YouTube Search Terms
- "Flutter animations tutorial"
- "Flutter implicit animations"
- "AnimatedContainer Flutter"
- "Hero animations Flutter"
- "Custom animations Flutter"

## App Contents
- `lib/main.dart` — app entry point and route configuration
- `lib/screens/home_screen.dart` — navigation dashboard
- `lib/screens/implicit_animations_screen.dart` — implicit animation examples
- `lib/screens/explicit_animations_screen.dart` — explicit animation examples
- `lib/screens/hero_animations_screen.dart` — Hero widget transitions
- `lib/screens/custom_transition_screen.dart` — custom page transitions

## Features
- AnimatedContainer, AnimatedOpacity, AnimatedPositioned, AnimatedCrossFade, TweenAnimationBuilder
- AnimationController, Tween animations, CurvedAnimation, AnimatedBuilder
- Hero widget with matching tags and custom flight shuttle builder
- Custom page transitions with PageRouteBuilder

## How to run
1. Open the `DAY_9` folder in VS Code.
2. Run `flutter pub get`.
3. Start the app with `flutter run`.

## Notes
This sample project is built to highlight animation techniques for learning and experimentation.
